# iSponsorBlockTV for Home Assistant

A permission-reduced fork of [bertybuttface/addons](https://github.com/bertybuttface/addons), containing only the iSponsorBlockTV wrapper. The upstream application is unchanged.

Add `https://github.com/robhanlon22/ha-isponsorblocktv` under **Settings → Apps → App store → Repositories**. Install iSponsorBlockTV, then follow the [setup instructions](isponsorblocktv/DOCS.md).
